# Install License Plate Game on a Phone

License Plate Game is designed to work well in a phone browser and can be added to the phone home screen so it behaves more like an app.

## iPhone / iPad

Use Safari.

1. Open the License Plate Game website in Safari.
2. Tap the Share button.
3. Scroll down and tap **Add to Home Screen**.
4. Confirm the name.
5. Tap **Add**.

The app icon will appear on the home screen.

## Android

Use Chrome.

1. Open the License Plate Game website in Chrome.
2. Tap the three-dot menu.
3. Tap **Add to Home screen** or **Install app**.
4. Confirm the install.

The app icon will appear on the home screen.

## Notes

- Login is still required.
- If the app is updated, refresh the browser/app view.
- If something looks stale, close and reopen the app icon.
